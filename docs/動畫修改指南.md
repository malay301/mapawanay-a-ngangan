# 動畫與表情修改指南

所有表情與動作都寫在 **`presentation.js`**，可以直接在 GitHub 網頁上改，不用安裝任何東西。

## 怎麼改

1. 打開 https://github.com/malay301/mapawanay-a-ngangan/blob/main/presentation.js
2. 按右上角的鉛筆圖示（Edit this file）。
3. 用瀏覽器的搜尋（Ctrl+F／⌘F）找你要改的那句台詞或旁白。
4. 改完按 **Commit changes**。
5. 打開 `sw.js`，把第 2 行 `const CACHE = '…';` 引號裡的名字隨便改一個新的（例如加上今天日期），再 Commit 一次。這一步是讓手機上已安裝的版本知道要更新。
6. 等一兩分鐘，重新整理遊戲網頁。

檔案裡有兩區：上面是 GPT 寫的動作（約第 113–245 行），下面「全劇表情與動作」是後來逐句補的，照劇情順序排，每段開頭有 `// —— 第一章｜阿公房間・手機 ——` 這種標題，方便找。

## 一、改某一句台詞的表情

找到這種行：

```js
LINE_EMOTIONS.set("……扳開了，啊——割到手指了。", 'pain');
```

把最後的英文換成想要的表情：

| 寫法 | 表情 | 寫法 | 表情 |
| --- | --- | --- | --- |
| `neutral` | 平靜 | `worried` | 不安 |
| `happy` | 開心 | `pain` | 痛（皺眉、咬牙） |
| `gentle` | 溫柔 | `smirk` | 調侃 |
| `angry` | 生氣 | `awkward` | 尷尬苦笑 |
| `sad` | 難過 | `serious` | 認真 |
| `surprised` | 驚訝 | `thinking` | 思考 |

GPT 那一區是一組一組寫的（`directLines('sad', [ … ])`），同一組的句子共用一個表情。想改其中一句，最簡單的做法是在檔案最後加一行 `LINE_EMOTIONS.set("那句台詞", '新表情');`，最後寫的會蓋過前面的。

## 二、刪掉某一句旁白的動作

找到 `directScene("那句旁白", …);` 開頭的那一行，**整行刪掉**就好。刪掉後那句旁白照常出現，只是沒有動作。

## 三、修改或新增動作

格式是：

```js
directScene("旁白原文，一字不差", 步驟1, 步驟2, …);
```

可以用的步驟：

| 步驟 | 意思 | 例子 |
| --- | --- | --- |
| `swalk(誰, [x, y], 朝向)` | 走到某一格 | `swalk('mingde', [4, 3], 0)` |
| `spose(誰, 'sit')`／`'stand'` | 坐下／站起來 | `spose('you', 'sit')` |
| `spose(誰, '動作', '表情')` | 只換表情（其他動作名稱只是標記，不會晃動） | `spose('yuzhen', 'pause', 'sad')` |
| `sprop(誰, '物品', 'take')` | 拿起東西 | `sprop('you', 'letter', 'take')` |
| `sprop(誰, '物品', 'place', [x, y])` | 把東西放到某個位置（像素座標） | `sprop('you', 'letter', 'place', [76, 69])` |
| `Stage.cast(誰, [x, y, 朝向])` | 讓角色直接出現在某處 | `Stage.cast('mingde', [6, 7, 1])` |
| `Stage.exit(誰)` | 讓角色離場 | `Stage.exit('yuzhen')` |
| `Stage.fade(起, 迄, 毫秒)` | 畫面變暗或變亮（1 全黑，0 正常） | `Stage.fade(1, 0, 900)` |
| `Stage.wait(毫秒)` | 停頓 | `Stage.wait(600)` |

- **誰**：`'you'` 奕翔、`'mingde'` 明德、`'yuzhen'` 玉珍、`'shichang'` 世昌、`'jianhe'` 建和、`'wenbin'` 文彬。
- **朝向**：0 朝下、1 朝上、2 朝右、3 朝左。
- **格子座標**：左上角是 [0, 0]，往右 x 變大、往下 y 變大。堂屋的座位：明德 [4, 3]、玉珍 [6, 3]、世昌 [8, 3]、建和 [3, 6]、文彬 [5, 6]、奕翔 [7, 6]；長桌在 x 3–8、y 4–5。
- **像素座標**（放東西用）：格子數 × 16 + 8。例如桌面中間大約是 [96, 72]。
- 物品名稱：`tengben` 謄本、`letter` 信、`photo` 照片、`fragment` 殘片、`qu` 麴、`cup` 杯子、`phone` 手機、`paper` 紙、`notebook` 筆記本、`archive` 影本。

## 注意

- **旁白和台詞原文必須一字不差**，連標點都要一樣，否則不會生效（不會壞掉，只是沒有效果）。改了劇本的台詞，這裡也要跟著改。
- 每個步驟之間用半形逗號 `,` 隔開；文字用引號包起來；行尾是 `);`。
- 少一個括號或引號，整個動畫系統會失效。改完如果遊戲怪怪的，到 GitHub 的「History」把那次修改還原，或告訴 Claude 你改了哪裡。
- 目前為了不讓畫面晃動，點頭、低頭、搖頭等小動作只會換表情；打開、摺起、翻面、寫字等物品動作也不播放。會播放的只有走路、坐下站起、拿起放下、進出場、淡入淡出。
