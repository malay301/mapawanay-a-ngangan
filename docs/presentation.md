# 劇情表情與動作

`presentation.js` 管理表情與演出；劇情分支、線索、時間及背包仍由 `index.html` 控制。

## 表情

六位角色都有十二種表情：`neutral`（平靜）、`happy`（開心）、`angry`（生氣）、`sad`（難過）、`surprised`（驚訝）、`worried`（不安）、`gentle`（溫柔）、`pain`（痛：皺眉、擠眼、咬牙）、`smirk`（調侃）、`awkward`（尷尬苦笑）、`serious`（認真）、`thinking`（思考）。對話頭像、立繪及正面地圖人物共用當句情緒；名字旁不顯示情緒文字，只靠表情呈現。

既有台詞在 `LINE_EMOTIONS` 明確指定情緒，也可以直接寫：

```js
say('mingde', '可是現在要找，也找不回來了。', 'sad');
```

`presentation.js` 最後的「全劇表情與動作」區段逐句指定了每一句台詞的表情，並替旁白補上人物動作；旁白裡的動作帶著情緒時，動作結束後會顯示該人物的頭像與表情。遊戲中組合出來的句子（提示、拿錯證物、推理更正）由 `emotionFor()` 依類型給表情。未指定的台詞使用平靜表情。

## 動作

`NARRATIVE_CUES` 以完整旁白文字對應一組依序執行的動作。修改旁白時，請同步修改對應文字；回歸檢查會檢查指令仍對應劇本。也可把動作直接傳給 `act`，適合動態組合的台詞：

```js
act('你把紙放在長桌的空位上。', [
  Stage.walk('you', [9, 4], 3),
  Stage.prop('you', 'tengben', 'place', [136, 72])
]);
```

- `walk`：目的地為地圖格座標；最後參數為朝向（0 下、1 上、2 右、3 左）。沿可行走路徑移動，目的地有人時停在附近。
- `pose`：支援站起、坐下、點頭、搖頭、俯身、揮手、伸手及調整眼鏡／耳機，可同時指定情緒。
- `prop`：支援拿起、放下、打開、摺起、翻面、書寫、紙角飄動與收進口袋。放置座標為地圖像素，物品會留在該位置。
- `room`：角色換場。`away`／`back` 用於 NPC 暫時離開的鏡頭，例如到車邊拿照片，回來後恢復主角及其他人的原位置。
- `cast`／`exit`：角色進出場；通常用於門口，避免在行走途中切換角色位置。
- `fade(from, to, 毫秒)`／`wait(毫秒)`：過場用的淡入淡出與停頓。
- 沒有文字的過場：`S.log.push({ w: '!', steps: [...] })`，播完自動接下一句（第一章開場、第三章入夜、結局走到屋外都用這個）。

動作不會自動推進對話。演出時一般移動與選項暫停；演出中點一下會直接演完（不跳過台詞，並短暫忽略連點）；「略過動作」或 Esc 會依序套用所有完成狀態。物品特寫與大立繪在演出時暫時收起，以免遮住地圖動作。回憶、假設與引用中的動作不會直接套到當前場景。

動畫進度只存在記憶體；完整劇情段落結束後，角色位置、物品位置及持握物品隨原有存檔流程保存。重新整理會回到最近一次儲存的劇情節點。舊存檔缺少演出欄位時會自動採用預設值。

## 驗證與更新

執行 `node tests/presentation-smoke.mjs`，檢查表情、實際動畫畫面變化、快速點擊、略過、存檔、三章代表場景、減少動態效果，以及 Service Worker 更新與離線播放。測試不涵蓋所有劇情選擇組合。

新增或修改演出資源後，更新 `sw.js` 的快取版本；新資源也要加入 `FILES`，確保離線可用。`presentation.js` 與 `index.html` 必須一起部署。
