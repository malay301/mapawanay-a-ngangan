# 雲端訪客簿設定（Supabase）

玩家在結局畫面按「寫好了，交給文彬」時，遊戲會在背景把這一頁送到 Supabase 雲端資料庫。
玩家看到的畫面和操作都跟原本一樣；送不出去時（沒網路、服務暫停），這一頁仍存在玩家裝置上，
下次有網路打開遊戲會自動補送，畫面上的「複製這一頁／下載這一頁」也都還在。

製作團隊到 `admin.html`（例如 https://malay301.github.io/mapawanay-a-ngangan/admin.html ）登入後，
可以看全部回饋、平均分數、搜尋，並下載成文字檔或 Excel 可開的 CSV。

## 一次性設定（約 10 分鐘）

1. **註冊**：打開 https://supabase.com ，按「Start your project」，用 GitHub 帳號登入最快。
2. **建專案**：按「New project」。
   - Name：`mapawanay-guestbook`（隨意）
   - Database Password：按「Generate a password」，自己存起來（之後用不太到）
   - Region：選 **Northeast Asia (Tokyo)** 或 **Southeast Asia (Singapore)**
   - Plan：Free
   - 按「Create new project」，等一兩分鐘建好。
3. **建資料表**：左側選單「SQL Editor」→「New query」，把本 repo 的 `supabase/setup.sql` 整份貼上，
   **把最下面的 `你的Email@example.com` 換成你自己的 Email**，按「Run」。看到 Success 就好。
4. **建立你的後台帳號**：左側「Authentication」→「Users」→「Add user」→「Create new user」，
   填同一個 Email 和一組密碼，勾選「Auto Confirm User」，按建立。
5. **關掉公開註冊**：「Authentication」→「Sign In / Providers」（舊版介面在「Providers」或「Settings」），
   把「Allow new users to sign up」關掉並儲存。這樣只有你建立的帳號能登入。
6. **拿兩個公開值**：左上方專案名稱旁的「Connect」或「Project Settings → API Keys / Data API」，複製：
   - **Project URL**（像 `https://abcdefghijkl.supabase.co`）
   - **Publishable key**（`sb_publishable_` 開頭；舊版介面叫「anon public」）
   這兩個本來就是公開的，可以直接貼給 Claude，或自己填進 `cloud-config.js`。
   **不要**貼 secret key、service_role key 或資料庫密碼。

## 安全設計

- 網站上的公開金鑰只能「新增」訪客簿，不能讀、改、刪（資料表開啟 RLS，只對 anon 開放 insert）。
- 每格答案有長度上限，全站每分鐘最多收 60 筆、總數最多 20000 筆，防止有人灌資料。
- 只有 `setup.sql` 裡指定 Email 的帳號登入後台時才讀得到資料；公開註冊已關閉。
- 回饋只有隨機的「借來的名字」與編號，不收真實姓名。

## 平常查看

- 後台頁：`admin.html`，用第 4 步的 Email 和密碼登入。
- 也可以在 Supabase 後台「Table Editor → guestbook」直接看、刪除測試資料，或用「Export → CSV」。

## 注意

- Supabase 免費專案一段時間（約一週）沒有使用可能會被暫停。登入 Supabase 後台按「Restore」即可恢復；
  暫停期間交出的回饋會留在玩家裝置上排隊，恢復後玩家再打開遊戲就會補送。活動前一兩天建議先打開後台確認一下。
- 若要換專案，只要改 `cloud-config.js` 的兩格。
