# 訪客簿寄信設定（Web3Forms）

玩家在結局畫面按「寫好了，交給文彬」時，遊戲會在背景把這一頁寄到製作團隊的信箱。
玩家看到的畫面和操作都跟原本一樣，不會看到外部表單；寄不出去時（沒網路、服務暫停），
這一頁仍存在玩家裝置上，下次有網路打開遊戲會自動補寄，「複製這一頁／下載這一頁」也都還在。

## 一次性設定（約 2 分鐘，不用註冊帳號）

1. 打開 https://web3forms.com ，在首頁「Create your Access Key」的欄位輸入收信信箱，按送出。
2. 到那個信箱收信（寄件者 Web3Forms，找不到請看垃圾郵件），信裡有一串 **Access Key**
   （長得像 `a1b2c3d4-xxxx-xxxx-xxxx-xxxxxxxxxxxx`）。
3. 把 Access Key 填進 `mail-config.js` 的 `key`（或貼給 Claude 代填），合併上線即可。

Access Key 設計上就是放在公開網頁裡的：拿到它只能寄信到綁定的信箱，看不到信箱地址，所以信箱不會出現在網站或 GitHub 上。

## 收到的信

- 主旨：`《被遺忘的名字》訪客簿｜提水的旅人（123）`
- 內容：借來的名字、結局、未走到的對話段數、交出時間，接著依序是「我的心得」與七題回答。
- 同一位玩家交出後又「翻回去改一改」再交，會收到第二封，以最新的為準。

## 注意

- Web3Forms 免費方案每月 250 封，一般場次夠用；超過時寄不出去的頁面會留在玩家裝置上排隊。
- 建議在信箱設一個篩選器，把主旨含「訪客簿」的信自動加標籤，方便整理。
- 想換收信信箱：用新信箱再拿一把 Access Key，替換 `mail-config.js` 即可。
