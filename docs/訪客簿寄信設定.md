# 訪客簿寄信設定（FormSubmit）

玩家在結局畫面按「寫好了，交給文彬」時，遊戲會在背景透過 FormSubmit（https://formsubmit.co ，免費、不用註冊、不用金鑰）
把這一頁寄到製作團隊的信箱。玩家看到的畫面和操作都跟原本一樣，不會看到外部表單；
寄不出去時（沒網路、服務暫停、信箱還沒啟用），這一頁仍存在玩家裝置上，下次有網路打開遊戲會自動補寄，
「複製這一頁／下載這一頁」也都還在。

## 一次性啟用（只要點一下）

1. 上線後，自己先玩到結局，在訪客簿隨便寫一句，按「寫好了，交給文彬」。
2. 收信信箱會收到 FormSubmit 寄來的「Activate Form」信（找不到請看垃圾郵件），按信裡的 **Activate Form**。
3. 完成。之後每位玩家交出都會寄一封信過來。啟用前交出的那一頁會留在那台裝置上，下次打開遊戲時補寄。

（選做）啟用後 FormSubmit 會再寄一封信，裡面有一串隨機代碼。把 `mail-config.js` 的 `to` 換成那串代碼，
信箱地址就完全不會出現在網站上。現在信箱是用 base64 編碼存放，一般爬蟲抓不到，但懂程式的人解得開。

## 收到的信

- 主旨：`《被遺忘的名字》訪客簿｜提水的旅人（123）`
- 內容（表格）：借來的名字、結局、未走到的對話段數、交出時間，接著依序是「我的心得」與七題回答。
- 同一位玩家交出後又「翻回去改一改」再交，會收到第二封，以最新的為準。

## 注意

- 建議在信箱設篩選器，把主旨含「訪客簿」的信自動加標籤，方便整理。
- 想換收信信箱：把新信箱用 base64 編碼後填進 `mail-config.js` 的 `to`（或直接填信箱），再重新啟用一次。
