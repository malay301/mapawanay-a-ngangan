《被遺忘的名字 Mapawanay a ngangan》像素版｜網頁版・App 版
==========================================================

這個資料夾就是完整的遊戲，不需要安裝任何程式，也不需要網路帳號。

一、自己先玩
  直接用瀏覽器打開 index.html 就能玩。
  （用檔案打開時不能「安裝成 App」，也不會離線快取；放上網路後才有。）

二、放上網路（三選一，都免費）
  1. Netlify Drop（最簡單）
     打開 https://app.netlify.com/drop ，把整個資料夾拖進去，
     幾秒後會拿到一個 https 網址。登入帳號後網址可以長期保留、改名。
  2. itch.io（適合遊戲展示頁）
     建立新專案 → Kind of project 選「HTML」→ 上傳「被遺忘的名字_網頁版.zip」
     → 勾選「This file will be played in the browser」。
     建議視窗大小：寬 480、高 900，並勾選「Mobile friendly」。
  3. GitHub Pages
     把資料夾內容放進一個 GitHub 儲存庫，Settings → Pages 啟用即可。

三、在手機上變成 App
  用手機打開上面拿到的網址：
  ・Android（Chrome）：首頁會出現「安裝成 App」按鈕，或用選單的「安裝應用程式」。
  ・iPhone／iPad（Safari）：點「分享」→「加入主畫面」。
  裝好後會出現在主畫面，全螢幕開啟；打開過一次之後，沒有網路也能玩。
  進度會自動存在這支手機上。

四、想上架 Google Play／App Store
  先完成「二」取得網址，再到 https://www.pwabuilder.com 貼上網址，
  可以產生 Android（Google Play）與 iOS 的上架套件。
  上架需要開發者帳號（Google Play 一次性費用；Apple 為年費），
  iOS 套件需要在 Mac 上用 Xcode 送審。

五、更新遊戲
  之後如果修改了內容，用新的資料夾覆蓋網站上的舊檔案即可。
  已安裝的手機在有網路時打開，會自動換成新版。
